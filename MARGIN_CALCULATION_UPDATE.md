# Обновление логики расчета маржи для множественных позиций

## Проблема

Ранее система рассчитывала маржу для каждой позиции отдельно, что не гарантировало достижение целевой итоговой маржи (например, 30%) по всем позициям в совокупности.

## Решение

Создан новый модуль `MultiPositionCalculator` с логикой расчета, которая обеспечивает точное достижение целевой маржи для всего заказа.

## Новые файлы

### `app/services/multi_position_calculator.py`
- **MultiPositionCalculator** - основной класс для расчета множественных позиций
- **calculate_multi_position_prices()** - расчет с единой итоговой маржой
- **calculate_legacy_single_position()** - обратная совместимость для одной позиции

## Измененные файлы

### `app/routes/main.py`
- Интеграция нового калькулятора
- Автоматический выбор метода расчета (одна/множественные позиции)
- Сохранение обратной совместимости

## Принцип работы

### 1. Расчет затрат для каждой позиции
```python
# Для каждой позиции рассчитываются:
- Затраты на закупку
- Логистика (пропорционально весу)
- Пошлина
- Комиссия за конвертацию
- Кредитные затраты
- Общие затраты на единицу
```

### 2. Расчет общего коэффициента цены
```python
# Общие затраты по всем позициям
total_costs = sum(position_costs)

# Целевая выручка с учетом маржи
target_revenue = total_costs / (1 - target_margin / 100)

# Коэффициент для всех позиций
price_coefficient = target_revenue / total_costs
```

### 3. Применение коэффициента
```python
# Цена каждой позиции
final_price = position_cost * price_coefficient

# Итоговая маржа точно равна целевой
actual_margin = (total_revenue - total_costs) / total_revenue * 100
```

## Пример расчета

- **Фактическая маржа**: 30.00% ✅

### Цены по позициям:
- **Позиция 1**: 1,782.22 руб./шт. (маржа: 30.00%)

## Преимущества

1. **Точность**: Итоговая маржа точно соответствует заданной
2. **Справедливость**: Все позиции получают одинаковый коэффициент маржи
3. **Прозрачность**: Понятная логика расчета
4. **Совместимость**: Старые формы с одной позицией работают без изменений
5. **Гибкость**: Поддержка любого количества позиций

## Обратная совместимость

- **Одна позиция**: Используется старый метод `calculate_selling_price()`
- **Множественные позиции**: Используется новый `MultiPositionCalculator`
- **Автоматический выбор**: Система сама определяет метод расчета
