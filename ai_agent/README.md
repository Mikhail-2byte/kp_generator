# AI Agent для KP Generator

AI консультант на базе OpenRouter API для ответов на вопросы по документации проекта и расчета логистики.

## 🚀 Возможности

- 📚 **Ответы на вопросы** по документации проекта (инструкции, руководства)
- 🚚 **Расчет логистики** для грузов
- 💬 **Интерактивный диалог** через веб-интерфейс
- 🧠 **Reasoning mode** для более глубокого анализа
- 🔄 **Кеширование** ответов для быстрой работы
- 📊 **Мониторинг использования** с детальной статистикой
- ⚡ **Fallback режим** при недоступности API
- 🔐 **Безопасное хранение** API ключей

## 📦 Установка

### 1. Зависимости

Убедитесь, что установлены все необходимые зависимости:

```bash
pip install -r requirements.txt
```

### 2. Настройка API ключа

**ВАЖНО**: Никогда не храните API ключи в коде!

1. Получите API ключ на [OpenRouter](https://openrouter.ai/keys)
2. При создании ключа:
   - Установите разумные лимиты использования
   - Установите срок действия или оставьте без ограничения
   - Рекомендуется добавить небольшой баланс ($5-10)

3. Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

4. Отредактируйте `.env` и установите свой ключ:

```env
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ-здесь
OPENROUTER_MODEL=xiaomi/mimo-v2-flash:free
```

### 3. Применение миграций БД

Для работы мониторинга необходимо применить миграции:

```bash
flask db upgrade
```

или

```bash
alembic upgrade head
```

### 4. (Опционально) Настройка Redis

Для кеширования ответов установите Redis:

```bash
# Windows (через WSL или Memurai)
# Linux/Mac
sudo apt-get install redis-server  # Ubuntu/Debian
brew install redis                 # macOS

# Включите в .env
REDIS_ENABLED=true
REDIS_HOST=localhost
REDIS_PORT=6379
```

## 🎯 Использование

### Веб-интерфейс

1. Запустите приложение Flask
2. Перейдите на `/ai-agent`
3. Задавайте вопросы в чате

### Терминальный интерфейс

```bash
python ai_agent/run.py
```

Доступные команды:
- `help` или `?` - показать справку
- `clear` или `cls` - очистить историю диалога
- `exit`, `quit` или `выход` - выйти

**Расчет логистики:**
- "Рассчитай логистику для 1000 кг в Москву"
- "Сколько стоит доставка 2 тонн в Екатеринбург?"
- "Логистика для 500 кг в Читу тралом"

## ⚙️ Конфигурация

Все настройки задаются через переменные окружения в `.env`:

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `OPENROUTER_API_KEY` | API ключ OpenRouter | **обязательно** |
| `OPENROUTER_MODEL` | Модель для использования | `xiaomi/mimo-v2-flash:free` |
| `OPENROUTER_TIMEOUT` | Timeout запросов (сек) | `60` |
| `OPENROUTER_REASONING_ENABLED` | Включить reasoning | `true` |
| `AI_FALLBACK_ENABLED` | Fallback при ошибках | `true` |
| `AI_USAGE_MONITORING` | Мониторинг использования | `true` |
| `AI_MAX_HISTORY_LENGTH` | Макс. длина истории | `20` |
| `AI_CACHE_TTL` | Время жизни кеша (сек) | `86400` (24ч) |
| `REDIS_ENABLED` | Включить Redis кеш | `false` |

Подробнее см. `.env.example`

## 🐛 Troubleshooting

### "OPENROUTER_API_KEY не установлен"

**Решение**: Создайте `.env` файл с ключом или установите переменную окружения

### "API ключ недействителен"

**Возможные причины**:
1. Ключ истек - создайте новый на OpenRouter
2. Ключ отозван - проверьте на OpenRouter
3. Недостаточно баланса - пополните счет

**Решение**: Зайдите на [OpenRouter Keys](https://openrouter.ai/keys) и проверьте статус

### "Превышен лимит запросов (429)"

**Причина**: Достигнут rate limit OpenRouter

**Решение**:
1. Подождите несколько минут
2. Увеличьте лимиты в настройках ключа
3. Включите кеширование для снижения запросов

### Ключ становится серым/зачеркнутым

**Причины**:
1. **Истек срок действия** - при создании ключа был установлен expiration date
2. **Достигнут лимит** - превышен установленный лимит использования
3. **Нулевой баланс** - закончились средства на счете

**Решение**:
1. Проверьте статус на OpenRouter
2. Создайте новый ключ без срока истечения
3. Установите адекватные лимиты или уберите их
4. Пополните баланс (рекомендуется $5-10)

### Redis недоступен

**Симптомы**: Warning "Redis кеш недоступен"

**Решение**:
1. Убедитесь что Redis запущен: `redis-cli ping`
2. Проверьте настройки в `.env`
3. Или отключите Redis: `REDIS_ENABLED=false`

## 📈 Мониторинг

### Статистика использования

Доступна в админ-панели `/admin/ai-agent`:

- Общее количество запросов
- Использовано токенов
- Среднее время ответа
- Количество ошибок
- Cache hit rate
- Распределение ошибок по типам
- Топ запросов пользователей

### Логирование

Все действия логируются в БД (таблица `ai_agent_usage`):
- Timestamp запроса
- ID пользователя
- Токены (request + response)
- Время ответа
- Тип ошибки (если была)
- Cache hit
