# AI Agent для KP Generator

AI консультант на базе Xiaomi Mimo V2 через OpenRouter API для ответов на вопросы по документации проекта и расчета логистики.

## Возможности

- 📚 Ответы на вопросы по документации проекта (инструкции, руководства)
- 🚚 Расчет логистики для грузов
- 💬 Интерактивный диалог через терминал
- 🧠 Reasoning mode для более глубокого анализа

## Установка

1. Убедитесь, что установлены зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте API ключ OpenRouter:
   - Получите ключ на https://openrouter.ai/
   - Создайте файл `.env` в корне проекта или установите переменную окружения:
   ```bash
   export OPENROUTER_API_KEY=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
   ```

## Запуск

### Проверка установки

Перед первым запуском проверьте, что все импорты работают:

```bash
python ai_agent/test_imports.py
```

### Запуск агента

Рекомендуемый способ (обходит проблемы с кодировкой):

```bash
python ai_agent/run.py
```

Альтернативные способы:

```bash
python -m ai_agent.main
```

или

```bash
cd ai_agent
python run.py
```

## Использование

После запуска вы увидите приглашение для ввода. Доступные команды:

- `help` или `?` - показать справку
- `clear` или `cls` - очистить историю диалога
- `exit`, `quit` или `выход` - выйти из программы

### Примеры вопросов

**По документации:**
- "Как обработать тендер?"
- "Как работает расчет логистики?"
- "Какие инструкции есть для работы с тендерами?"

**Расчет логистики:**
- "Рассчитай логистику для 1000 кг в Москву"
- "Сколько стоит доставка 2 тонн в Екатеринбург?"
- "Логистика для 500 кг в Читу"
- "Рассчитай доставку 1.5 тонн тралом в Москву"

## Структура

```
ai_agent/
├── config.py              # Конфигурация (API ключи, пути)
├── knowledge_base.py       # Загрузка и управление документацией
├── logistics_helper.py     # Обертка для расчета логистики
├── agent.py                # Основной класс AI агента
├── main.py                 # Точка входа с терминальным интерфейсом
├── run.py                  # Обертка для запуска (решает проблемы с кодировкой)
├── test_imports.py         # Скрипт для проверки импортов
└── data/                   # Данные для анализа агента
    ├── instructions/       # Инструкции проекта (копии из static/instructions/)
    │   ├── Инструкция №1.txt
    │   ├── Инструкция №2.txt
    │   ├── Инструкция №3.txt
    │   └── Инструкция №4.txt
    └── documentation/      # Документация проекта (копии из docs/)
        ├── COMPLETE_GUIDE.md
        ├── SETUP.md
        ├── PROJECT_STRUCTURE.md
        ├── MULTI_POSITION_INTEGRATION.md
        ├── USER_MANAGEMENT.md
        ├── BUDGET_EXCEL_FLOW.md
        ├── CHANGELOG.md
        └── INSTRUCTIONS_RU.txt
```

### Структура данных

Все данные, которые анализирует агент, находятся в папке `ai_agent/data/`:
- **Инструкции** (`data/instructions/`) - текстовые инструкции по работе с системой
- **Документация** (`data/documentation/`) - Markdown файлы с полным описанием проекта

Это обеспечивает:
- **Самодостаточность** - все данные агента в одном месте
- **Независимость** - не зависит от структуры основного проекта
- **Портативность** - можно легко скопировать папку `ai_agent/` в другой проект

## Примечания

- Агент использует reasoning mode для более качественных ответов
- История диалога сохраняется в рамках одной сессии
- Для расчета логистики требуется указать вес и город назначения
- Агент автоматически находит релевантные фрагменты документации по запросу
