# База знаний AI агента

Эта папка содержит данные, которые использует AI агент для ответов на вопросы пользователей.

## Структура

```
ai_agent/data/
├── instructions/      # Инструкции для агента (.txt файлы)
└── documentation/     # Документация проекта (.md и .txt файлы)
```

## Инструкции (instructions/)

Здесь размещайте текстовые файлы (.txt) с инструкциями для агента.

**Примеры использования:**
- Процедуры работы с системой
- Правила согласования документов
- Инструкции по отправке коммерческих предложений
- Другие рабочие инструкции

**Формат:**
- Первая строка файла будет использована как заголовок
- Остальное содержимое - как текст инструкции
- Кодировка: UTF-8

## Документация (documentation/)

Здесь размещайте файлы документации (.md или .txt) проекта.

**Приоритетные файлы (загружаются первыми):**
- COMPLETE_GUIDE.md
- SETUP.md
- PROJECT_STRUCTURE.md
- MULTI_POSITION_INTEGRATION.md
- USER_MANAGEMENT.md
- BUDGET_EXCEL_FLOW.md
- CHANGELOG.md
- LOGISTICS_CALCULATION.md - Полная логика расчетов логистики
- MATERIALS_CATALOG.md - Справочник металлов (gb_materials)
- DUTY_RATES.md - Справочники пошлин (duty_rates, TNVED)

**Формат:**
- Для .md файлов: заголовок из первого `# Заголовок`
- Для .txt файлов: первая строка как заголовок
- Кодировка: UTF-8

## Как агент использует эти данные

1. **При инициализации**: Агент загружает все файлы и формирует системный промпт (до 5000 символов)

2. **При каждом запросе**: Агент ищет релевантные фрагменты по ключевым словам и фразам из запроса пользователя

3. **Поиск**: Используется умный поиск с учетом:
   - Совпадений слов в заголовках (более важны)
   - Совпадений слов в содержимом
   - Ключевых фраз (бюджет, согласование, расценка, отправка и т.д.)

4. **Результат**: Агент получает до 3 наиболее релевантных документов для формирования ответа

## Обновление данных

После добавления или изменения файлов:
- Перезапустите приложение, чтобы агент загрузил новые данные
- Или используйте функцию очистки кеша в админ-панели

## Специальная документация

### LOGISTICS_CALCULATION.md
Содержит полную логику расчетов логистики:
- Алгоритмы расчета (прямой, КНР→ЕКБ→Город)
- Формулы расчета по весу и объему
- Пороговые значения и правила выбора алгоритма
- Параметры транспорта (фура, трал)
- Тарифная сетка РФ
- Примеры расчетов

### MATERIALS_CATALOG.md
Описание справочника металлов:
- Структура данных (russian, gb, gost, price, workpiece_type)
- Типы заготовок (Лист, Прокат, Труба, Поковка)
- Примеры поиска материалов
- Правила работы агента со справочником

### DUTY_RATES.md
Описание справочников пошлин:
- Структура duty_rates.json (ручной справочник)
- Структура TNVED каталога (CSV)
- Правила поиска пошлин
- Примеры работы агента со справочниками

## Рекомендации

- Используйте понятные названия файлов
- Структурируйте содержимое с заголовками
- Добавляйте ключевые слова, которые могут использовать пользователи
- Регулярно обновляйте документацию при изменениях в системе
- При изменении логики расчетов обновляйте соответствующие документы
