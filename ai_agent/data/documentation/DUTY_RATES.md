# Справочники пошлин

## Обзор

В системе используются два источника информации о пошлинах:

1. **duty_rates.json** - Ручной справочник пошлин (добавляется администратором)
2. **TNVED каталог** - Расширенный каталог ТН ВЭД из CSV файла

Оба справочника объединяются в общий каталог для поиска.

## Структура duty_rates.json

Ручной справочник содержит записи с полями:

- **product** - Название товара/продукта
- **category** - Категория товара
- **duty_percent** - Процент пошлины (число, например: 5.0, 10.0, 0.0)

**Пример записи:**
```json
{
  "product": "Сталь конструкционная",
  "category": "Металлопрокат",
  "duty_percent": 5.0
}
```

**Особенности:**
- Записи добавляются администратором вручную
- Приоритет при поиске выше, чем у TNVED каталога
- Используется для часто используемых товаров

## Структура TNVED каталога

Каталог ТН ВЭД содержит расширенную информацию:

- **code** - Код ТН ВЭД
- **description** - Описание товара
- **keywords_display** - Ключевые слова для отображения
- **keywords_list** - Список ключевых слов для поиска
- **examples** - Примеры товаров
- **duty_text** - Текст пошлины (может быть "—" если не указана)
- **duty_percent** - Процент пошлины (извлекается из duty_text)

**Пример записи:**
```
code: "7214"
description: "Прочие прутки и профили из нелегированной стали"
keywords_display: "прутки стальные, профили стальные"
keywords_list: ["прутки", "стальные", "профили"]
examples: "квадрат, круг, шестигранник"
duty_text: "5%"
duty_percent: 5.0
```

## Как работает объединенный каталог

При поиске система:
1. Сначала ищет в ручном справочнике (duty_rates.json)
2. Затем ищет в TNVED каталоге
3. Объединяет результаты, приоритет у ручных записей
4. Сортирует: сначала ручные записи, затем по коду ТН ВЭД

## Как агент работает со справочниками

Агент имеет прямой доступ к справочникам через `DutyHelper` и может выполнять реальный поиск.

### 1. Поиск по названию товара

**Вопрос пользователя:** "Какая пошлина на сталь конструкционную?"

**Действия агента:**

- Автоматически использует `duty_helper.search_by_product("сталь конструкционную")`
- Получает записи из объединенного каталога (duty_rates + TNVED)
- Форматирует результаты через `format_duty_result()`
- Показывает процент пошлины и источник

**Пример ответа:**
"✅ Найдена пошлина:

**Товар:** Сталь конструкционная
**Категория:** Металлопрокат
**Пошлина:** 5%

📝 Источник: Ручной справочник"

### 2. Поиск по коду ТН ВЭД

**Вопрос пользователя:** "Какая пошлина по коду 7214?"

**Действия агента:**
- Автоматически определяет, что запрос - код ТН ВЭД (только цифры)
- Использует `duty_helper.search_by_code("7214")`
- Получает запись из TNVED каталога
- Форматирует и показывает результат

**Пример ответа:**
"✅ Найдена пошлина:

**Код ТН ВЭД:** 7214
**Товар:** прутки стальные, профили стальные
**Категория:** Прочие прутки и профили из нелегированной стали
**Пошлина:** 5%
**Примеры:** квадрат, круг, шестигранник

📋 Источник: Каталог ТН ВЭД"

### 3. Поиск по ключевым словам

**Вопрос пользователя:** "Какая пошлина на прутки?"

**Действия агента:**
- Искать по ключевым словам в обоих справочниках
- Показать все релевантные варианты
- Указать коды ТН ВЭД и проценты пошлин

**Пример ответа:**
"Найдены варианты для 'прутки':
1. Код 7214: Прочие прутки и профили из нелегированной стали - 5%
2. [Другие варианты]"

### 4. Если пошлина не найдена

**Вопрос пользователя:** "Какая пошлина на [неизвестный товар]?"

**Действия агента:**
- Сообщить, что товар не найден в справочниках
- Предложить уточнить название или найти по коду ТН ВЭД
- Предложить обратиться к администратору для добавления в ручной справочник

**Пример ответа:**
"Товар '[название]' не найден в справочниках пошлин. 
Рекомендации:
1. Уточните название товара или категорию
2. Если известен код ТН ВЭД, укажите его
3. Обратитесь к администратору для добавления товара в справочник"

## Формат пошлины

Пошлина может быть указана в разных форматах:

- **Число:** 5.0, 10.0, 0.0 (процент)
- **Текст:** "5%", "10%", "—" (если не указана)
- **Пустое значение:** пошлина не указана

**Важно:** Агент должен всегда показывать пошлину в процентах, даже если она 0%.

## Важные правила для агента

1. **Приоритет ручного справочника:**
   - Сначала показывайте результаты из duty_rates.json
   - Затем результаты из TNVED каталога

2. **Если найдено несколько вариантов:**
   - Показывайте все релевантные варианты
   - Группируйте по категориям или кодам ТН ВЭД
   - Указывайте источник (ручной справочник или TNVED)

3. **Если пошлина не указана:**
   - Честно сообщайте, что пошлина не найдена
   - Предлагайте альтернативные способы поиска
   - Не выдумывайте значения

4. **Формат ответа:**
   - Всегда указывайте процент пошлины
   - Для TNVED указывайте код
   - Показывайте описание и примеры, если доступны

5. **Поиск должен быть гибким:**
   - Поиск по частичному совпадению
   - Учет синонимов и ключевых слов
   - Учет регистра не важен

6. **Не добавлять записи:**
   - Агент НЕ может добавлять записи в справочники
   - Всегда направляйте пользователя к администратору

## Связь с расчетом коммерческого предложения

Пошлина используется в расчете продажной цены:

```
Пошлина на единицу = (Стоимость закупа + Логистика) × (Пошлина %) / 100
```

Агент должен понимать, что пошлина влияет на итоговую стоимость товара, и правильно объяснять это пользователям.
