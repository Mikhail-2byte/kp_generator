# Справочник металлов (GB Materials)

## Обзор

Справочник металлов содержит информацию о материалах с указанием русских и китайских (GB) стандартов, ГОСТ, цен и типов заготовок.

## Структура данных

Каждая запись в справочнике содержит следующие поля:

- **russian** - Русское название материала (например: "10", "15Г", "08пс")
- **gb** - Китайский стандарт GB или международный стандарт (например: "10", "12Mn", "AISI 439")
- **gost** - ГОСТ стандарт (например: "ГОСТ 1050-2013", "ГОСТ 16523-97")
- **price** - Цена материала (в юанях за кг, может быть пустой строкой)
- **workpiece_type** - Тип заготовки (Лист, Прокат, Труба, Поковка)
- **notes** - Дополнительные примечания (может быть пустым)

## Типы заготовок

Справочник содержит материалы в следующих типах заготовок:

1. **Лист** - Листовой материал
2. **Прокат** - Прокатный материал
3. **Труба** - Трубный материал
4. **Поковка** - Поковочный материал

**Важно:** Один и тот же материал может иметь разные цены для разных типов заготовок.

## Как агент работает со справочником

Агент имеет прямой доступ к справочнику через `MaterialsHelper` и может выполнять реальный поиск.

### 1. Поиск по русскому названию

**Вопрос пользователя:** "Найди материал 10"

**Действия агента:**
- Автоматически использует `materials_helper.search_by_russian("10")`
- Получает все записи из справочника, где `russian` содержит "10"
- Форматирует результаты через `format_material_result()`
- Показывает все варианты с разными типами заготовок
- Указывает цены для каждого типа
- Если цены нет, сообщает об этом

**Пример ответа:**
"✅ Найден материал:

**Русское название:** 10
**GB стандарт:** 10
**ГОСТ:** ГОСТ 1050-2013
**Цена:** 4.30 юань/кг
**Тип заготовки:** Лист"

### 2. Поиск по GB стандарту

**Вопрос пользователя:** "Какой русский аналог у 12Mn?"

**Действия агента:**
- Автоматически использует `materials_helper.search_by_gb("12Mn")`
- Получает записи из справочника, где `gb` содержит "12Mn"
- Форматирует и показывает результаты

**Пример ответа:**
"✅ Найдено материалов: 2

1. **10Г2** (GB: 12Mn, ГОСТ: ГОСТ 1050-2013) - 5.00 юань/кг (Лист)
2. **10Г2** (GB: 12Mn, ГОСТ: ГОСТ 1050-2013) - 5.00 юань/кг (Прокат)"

### 3. Поиск по ГОСТ

**Вопрос пользователя:** "Какие материалы есть по ГОСТ 1050-2013?"

**Действия агента:**
- Искать все записи с указанным ГОСТ
- Группировать по русским названиям
- Показать варианты с ценами

### 4. Предупреждение о неиспользуемых материалах

**Вопрос пользователя:** "Найди материал 08пс"

**Действия агента:**
- Найти запись
- Обнаружить предупреждение в поле `gb`
- Предупредить пользователя
- Предложить замену

**Пример ответа:**
"⚠️ ВНИМАНИЕ: Материал '08пс' НЕ ИСПОЛЬЗУЕТСЯ. Рекомендуется замена на '10' (ГОСТ 1050-2013)."

### 5. Поиск аналогов

**Вопрос пользователя:** "Есть ли аналог для AISI 439?"

**Действия агента:**
- Искать по полю `gb`
- Найти соответствие
- Показать русский стандарт и ГОСТ

**Пример ответа:**
"Материал AISI 439 соответствует русскому стандарту '0К360В' (ГОСТ 16523-97)."

## Особенности работы со справочником

1. **Один материал - несколько записей:**
   - Один и тот же материал может иметь разные цены для разных типов заготовок
   - Всегда показывайте все варианты

2. **Пустые поля:**
   - Если `price` пустое - цена не указана
   - Если `workpiece_type` пустое - тип заготовки не указан
   - Если `notes` пустое - примечаний нет

3. **Поиск должен быть гибким:**
   - Поиск по частичному совпадению в русском названии
   - Поиск по частичному совпадению в GB стандарте
   - Учет регистра не важен

4. **Формат цен:**
   - Цены указаны в юанях за килограмм
   - Формат: число с точкой (например: "4.30", "5.00")

## Примеры вопросов и ответов для агента

### Вопрос 1: "Сколько стоит материал 15 в виде листа?"
**Ответ:** "Материал '15' (ГОСТ 1050-2013) в виде листа стоит 4.50 юань/кг."

**Ответ:** "По ГОСТ 1050-2013 в справочнике есть следующие материалы: 08пс (не использовать, замена на 10), 10, 10Г2, 15, 15Г и другие. Уточните, какой материал вас интересует?"

### Вопрос 3: "Найди все варианты материала 10"
**Ответ:** "Материал '10' (GB: 10, ГОСТ 1050-2013) доступен в следующих вариантах:
- Лист: 4.30 юань/кг
- Прокат: 4.50 юань/кг  
- Труба: 5.00 юань/кг
- Поковка: 6.00 юань/кг"

### Вопрос 4: "Какой русский аналог у 12Mn?"
**Ответ:** "Материал 12Mn соответствует русскому стандарту '10Г2' (ГОСТ 1050-2013). Доступен в виде листа и проката по цене 5.00 юань/кг."

## Важные правила для агента

1. **Всегда проверяйте предупреждения** в поле `gb` на наличие текста "НЕ ИСПОЛЬЗОВАТЬ"

2. **Показывайте все варианты** если материал есть в нескольких типах заготовок

3. **Указывайте ГОСТ** при ответе о материалах

4. **Если цена не указана**, честно сообщайте об этом

5. **При поиске аналогов** используйте как русское название, так и GB стандарт

6. **Форматируйте ответы** с указанием всех релевантных полей: русское название, GB, ГОСТ, тип заготовки, цена
