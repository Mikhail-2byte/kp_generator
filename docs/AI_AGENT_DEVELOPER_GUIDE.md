# Руководство разработчика AI агента

## Архитектура

AI агент состоит из следующих основных компонентов:

### Основные модули

- **`agent.py`** - Главный класс AIAgent, оркестратор всех функций
- **`analytics_helper.py`** - Работа с данными 1С (CSV)
- **`logistics_helper.py`** - Расчет логистики
- **`materials_helper.py`** - Поиск материалов
- **`duty_helper.py`** - Расчет пошлин
- **`intent_extractor.py`** - Извлечение намерений из запросов
- **`validators.py`** - Валидация параметров
- **`formatters.py`** - Форматирование ответов
- **`suggestions.py`** - Генерация предложений и автодополнения
- **`cache_manager.py`** - Управление кешированием
- **`metrics.py`** - Сбор метрик производительности
- **`feedback.py`** - Сбор обратной связи
- **`exporters.py`** - Экспорт результатов
- **`interactive.py`** - Интерактивные элементы
- **`dashboard.py`** - Dashboard с метриками
- **`datasource.py`** - Абстракция источников данных

## Расширение функциональности

### Добавление нового типа запроса

1. Добавьте распознавание в `intent_extractor.py`
2. Добавьте обработку в `agent.py` в методе `chat()`
3. Обновите системный промпт в `_build_system_prompt()`

### Добавление нового типа графика

1. Добавьте метод в `analytics_helper.py` (например, `generate_chart_xxx()`)
2. Добавьте обработку в `agent.py`
3. Обновите кеширование графиков

### Добавление нового источника данных

1. Создайте класс, наследующий `DataSource` из `datasource.py`
2. Реализуйте методы `load_data()`, `get_categories()`, `search()`
3. Используйте `DataSourceFactory` для создания экземпляра

## Тестирование

### Unit-тесты

Тесты находятся в `tests/`:
- `test_formatters.py` - Тесты форматирования
- `test_validators.py` - Тесты валидации
- `test_intent_extractor.py` - Тесты извлечения намерений
- `test_suggestions.py` - Тесты предложений

### Интеграционные тесты

- `test_ai_agent_integration.py` - Интеграционные тесты агента

### Запуск тестов

```bash
pytest tests/
pytest tests/test_formatters.py -v
```

## Кеширование

Кеширование реализовано через Redis:
- AI ответы кешируются на основе сообщения
- Результаты аналитики кешируются с параметрами запроса
- Графики кешируются на 7 дней

## Метрики

Метрики собираются автоматически:
- Время выполнения запросов
- Использование памяти
- Счетчики запросов по типам
- Статистика ошибок

Доступ через `metrics_collector.get_summary()`

## Обратная связь

Система обратной связи позволяет пользователям оценивать ответы:
- Оценка от 1 до 5
- Комментарии
- Статистика по типам запросов

## Экспорт

Поддерживается экспорт в:
- CSV
- Excel (требует openpyxl)
- PNG (для графиков)

Файлы сохраняются во временную директорию.

## Подготовка к переходу на БД

Абстракция `DataSource` позволяет легко переключиться с CSV на БД:
1. Создайте `DatabaseDataSource` с подключением к БД 1С
2. Используйте `DataSourceFactory.create_source('database', ...)`
3. Обновите `AnalyticsHelper` для использования нового источника

## Логирование

Все модули используют стандартный Python logging:
```python
import logging
logger = logging.getLogger(__name__)
```

## Конфигурация

Настройки находятся в `config.py`:
- API ключи
- URL API
- Модель AI
- Таймауты
- Настройки кеширования
