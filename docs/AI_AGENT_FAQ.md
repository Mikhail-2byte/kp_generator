# FAQ по AI агенту

## Общие вопросы

### Что может делать агент?

Агент может:
- Искать данные в 1С (номенклатура, чертежи, заказчики, материалы)
- Показывать статистику и топ-листы
- Генерировать графики и визуализации
- Рассчитывать логистику
- Искать материалы
- Экспортировать результаты
- Сравнивать периоды и категории

### Как агент понимает запросы?

Агент использует многоуровневую систему распознавания:
1. Регулярные выражения для точных паттернов
2. Ключевые слова для общих запросов
3. Контекст из предыдущих сообщений

### Можно ли использовать агент без интернета?

Частично. Поиск в данных 1С, расчет логистики и материалов работают локально. Для общих вопросов требуется доступ к AI API.

## Работа с данными 1С

### Какие категории данных доступны?

Используйте запрос: "Какие категории доступны?" или "Покажи категории"

### Как искать по нескольким полям одновременно?

Используйте комбинированный поиск:
```
Найди в 1с чертеж 35.1774.000 СБ заказчик ВАЙЛДБЕРРИЗ
```

### Как получить данные за определенный период?

Используйте фильтры по датам:
```
Покажи тендеры с 01.01.2024 по 31.12.2024
```

### Как сравнить два периода?

Используйте запрос:
```
Сравни тендеры с 01.01.2024 по 31.03.2024 и с 01.04.2024 по 30.06.2024
```

## Графики и визуализация

### Какие типы графиков доступны?

- Обычные графики: топ заказчиков, материалы, менеджеры, цены
- Временные ряды: динамика по месяцам/кварталам/годам
- Scatter plots: корреляции (вес vs цена)
- Heatmaps: многомерные данные (заказчик vs менеджер)

### Как запросить график?

Добавьте к запросу: "покажи график", "с графиком" или "визуализируй"

### Графики не отображаются

Проверьте:
1. Есть ли данные для визуализации
2. Поддерживает ли фронтенд отображение base64 изображений
3. Проверьте логи на наличие ошибок

## Экспорт

### В какие форматы можно экспортировать?

- CSV - для табличных данных
- Excel - для расширенной работы с данными
- PNG - для графиков

### Где сохраняются экспортированные файлы?

Файлы сохраняются во временную директорию системы. Путь указывается в ответе агента.

### Как долго хранятся экспортированные файлы?

По умолчанию файлы удаляются через 24 часа. Можно настроить через `exporter.cleanup_old_files()`.

## Производительность

### Почему запросы медленные?

Возможные причины:
1. Первая загрузка данных 1С (ленивая загрузка)
2. Генерация графиков для больших объемов данных
3. Обращение к AI API для сложных запросов

### Как ускорить работу?

1. Используйте кеширование (включено по умолчанию)
2. Указывайте категорию для более точного поиска
3. Используйте фильтры для уменьшения объема данных

## Ошибки

### "Город не найден"

Проверьте:
1. Правильность написания города
2. Используйте полное название (например, "Санкт-Петербург" вместо "СПб")

### "Данные не найдены"

Возможные причины:
1. Опечатка в запросе
2. Данные отсутствуют в указанной категории
3. Используется другое название

Попробуйте:
- Более общий запрос
- Другую категорию
- Поиск по другому полю

### "Ошибка при обращении к AI"

Это может быть:
1. Проблема с API ключом
2. Превышение rate limit
3. Временная недоступность API

Агент автоматически использует fallback при ошибках.

## Обратная связь

### Как оценить ответ агента?

Используйте систему обратной связи (если реализована во фронтенде):
- Оценка от 1 до 5
- Комментарий (опционально)

### Зачем нужна обратная связь?

Обратная связь помогает:
- Улучшать качество ответов
- Определять проблемные области
- Собирать статистику использования

## Технические вопросы

### Как добавить новую категорию данных?

1. Добавьте CSV файл в `ai_agent/data/1с/`
2. Перезапустите приложение
3. Категория будет автоматически обнаружена

### Как переключиться с CSV на БД?

Используйте абстракцию `DataSource`:
1. Создайте `DatabaseDataSource` с подключением к БД
2. Обновите `AnalyticsHelper` для использования нового источника

### Как настроить кеширование?

Настройки кеширования находятся в `cache_manager.py`:
- TTL для различных типов данных
- Настройки Redis
- Инвалидация кеша
