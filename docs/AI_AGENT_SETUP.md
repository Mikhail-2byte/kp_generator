## 🚀 Первоначальная настройка

### Шаг 1: Проверка зависимостей

Убедитесь, что все необходимые пакеты установлены:

```bash
pip install -r requirements.txt
```

Ключевые зависимости:
- `requests` - для API запросов
- `python-dotenv` - для загрузки `.env`
- `redis` - для кеширования (опционально)
- `sqlalchemy` - для мониторинга

### Шаг 2: Применение миграций БД

Для работы мониторинга необходима таблица `ai_agent_usage`:

```bash
# Если используете Flask-Migrate
flask db upgrade

# Если используете Alembic напрямую
alembic upgrade head
```

Проверьте, что таблица создана:

```sql
SELECT * FROM ai_agent_usage LIMIT 1;
```

### Шаг 3: Настройка Redis (опционально)

Redis используется для кеширования ответов, что значительно снижает количество API запросов.

#### Windows:
Используйте [Memurai](https://www.memurai.com/) или WSL с Redis

#### Linux:
```bash
sudo apt-get update
sudo apt-get install redis-server
sudo systemctl start redis-server
sudo systemctl enable redis-server
```

#### macOS:
```bash
brew install redis
brew services start redis
```

Проверка работы:
```bash
redis-cli ping
# Должно вернуть: PONG
```

## 🔑 Получение API ключа OpenRouter

### 1. Регистрация

Перейдите на [OpenRouter](https://openrouter.ai/) и зарегистрируйтесь.

### 2. Создание API ключа

1. Откройте [страницу ключей](https://openrouter.ai/keys)
2. Нажмите "Create API Key"
3. **ВАЖНО**: Настройте параметры:

#### Рекомендуемые настройки:

**Для production:**
- **Name**: `KP Generator Production`
- **Rate Limit**: 100 requests/minute (или выше при необходимости)
- **Expiration**: No expiration (или установите большой срок)
- **Usage Limit**: $50/month (или установите под ваши нужды)

**Для development/testing:**
- **Name**: `KP Generator Dev`
- **Rate Limit**: 20 requests/minute
- **Expiration**: 90 days
- **Usage Limit**: $10/month

### 3. Пополнение баланса

Даже для бесплатных моделей рекомендуется добавить баланс $5-10:
1. Перейдите в [Billing](https://openrouter.ai/account)
2. Add Credits
3. Минимум $5

**Зачем?**
- Некоторые "бесплатные" модели могут требовать минимальный баланс
- Защита от внезапных изменений политики
- Возможность использовать платные модели при необходимости

### 4. Мониторинг использования

Регулярно проверяйте использование на [странице использования](https://openrouter.ai/activity):
- Количество запросов
- Потраченные средства
- Топ используемые модели

## ⚙️ Настройка переменных окружения

### Создание .env файла

1. Скопируйте шаблон:
```bash
cp .env.example .env
```

2. Отредактируйте `.env`:

```env
# ============================================
# OpenRouter AI API
# ============================================

# ОБЯЗАТЕЛЬНО: Ваш API ключ
OPENROUTER_API_KEY=sk-or-v1-ваш-реальный-ключ-здесь

# Модель (рекомендуемые)
OPENROUTER_MODEL=xiaomi/mimo-v2-flash:free

# Timeout (секунды)
OPENROUTER_TIMEOUT=60

# Reasoning (улучшает качество ответов)
OPENROUTER_REASONING_ENABLED=true

# ============================================
# AI Agent настройки
# ============================================

# Fallback при ошибках API
AI_FALLBACK_ENABLED=true

# Мониторинг использования
AI_USAGE_MONITORING=true

# Максимум сообщений в истории
AI_MAX_HISTORY_LENGTH=20

# Время жизни кеша (24 часа)
AI_CACHE_TTL=86400

# ============================================
# Redis кеш (опционально)
# ============================================

REDIS_ENABLED=true
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0
REDIS_PASSWORD=
```

### Безопасность .env файла

**КРИТИЧЕСКИ ВАЖНО:**

1. `.env` должен быть в `.gitignore`:
```bash
# Проверьте
cat .gitignore | grep ".env"
```

2. Права доступа (Linux/Mac):
```bash
chmod 600 .env
```

3. Никогда не коммитьте `.env` в git
4. Используйте разные ключи для dev/staging/production

## 📊 Мониторинг и статистика

### Доступ к админ-панели

URL: `https://your-domain.com/admin/ai-agent`

Требуется роль: `admin`

### Основные метрики

#### 1. Статус API ключа
- ✅ **Валиден** - ключ работает нормально
- ❌ **Невалиден** - ключ отозван или истек
- ⚠️ **Не установлен** - отсутствует в `.env`
- ❓ **Неизвестно** - ошибка проверки

#### 2. Статистика использования

**Период**: Выбирается через параметр `?days=30`

Метрики:
- **Всего запросов**: Общее количество
- **Токенов использовано**: Prompt + Completion токены
- **Среднее время ответа**: В миллисекундах
- **Количество ошибок**: Все типы ошибок
- **Cache hits**: Запросы из кеша
- **Cache hit rate**: Процент кешированных ответов

#### 3. Анализ ошибок

Типы ошибок:
- `auth_error` - Проблемы с API ключом
- `rate_limit` - Превышен лимит запросов
- `server_error` - Ошибки OpenRouter (5xx)
- `timeout` - Превышен timeout
- `connection_error` - Проблемы с сетью

#### 4. Топ запросов

Показывает самые частые вопросы пользователей за последние 7 дней.

**Применение:**
- Определение часто задаваемых вопросов
- Улучшение документации
- Добавление FAQ разделов

### Управление кешем

**Когда очищать кеш:**
- После обновления документации
- При изменении логики ответов
- Если замечены устаревшие ответы

**Как очистить:**
1. Админ-панель → "Управление кешем"
2. Кнопка "Очистить кеш"

**Проверка размера:**
- Показывается в админ-панели
- Записей в кеше
- Размер в KB

## 🐛 Устранение проблем

### Проблема: API ключ становится серым/зачеркнутым

**Симптомы:**
- В OpenRouter ключ отображается серым
- Зачеркнут или помечен как expired

**Причины и решения:**

#### Причина 1: Истек срок действия

**Как проверить:**
1. Зайдите на [OpenRouter Keys](https://openrouter.ai/keys)
2. Найдите свой ключ
3. Проверьте поле "Expires"

**Решение:**
```bash
# 1. Создайте новый ключ БЕЗ срока истечения
# 2. Обновите .env
OPENROUTER_API_KEY=новый-ключ

# 3. Перезапустите приложение
sudo systemctl restart kp-generator  # или ваш метод
```

#### Причина 2: Превышен лимит использования

**Как проверить:**
1. OpenRouter → Activity
2. Проверьте Usage vs Limit

**Решение:**
```bash
# Увеличьте лимит или создайте новый ключ с большим лимитом
# Или удалите лимит вообще (установите unlimited)
```

#### Причина 3: Нулевой баланс

**Как проверить:**
OpenRouter → Account → Credits

**Решение:**
Пополните баланс минимум на $5

### Проблема: "Превышен лимит запросов (429)"

**Симптомы:**
- Ошибка "rate limit exceeded"
- Пользователи не могут получить ответы

**Решения:**

#### 1. Краткосрочное
```bash
# Подождите несколько минут
# Лимиты обычно сбрасываются каждую минуту
```

#### 2. Среднесрочное
```bash
# Включите кеширование
REDIS_ENABLED=true
AI_CACHE_TTL=86400

# Перезапустите приложение
```

#### 3. Долгосрочное
1. Увеличьте rate limit в настройках ключа
2. Создайте несколько ключей для load balancing (требует доработки кода)
3. Переключитесь на платную модель (обычно выше лимиты)

### Проблема: Медленные ответы

**Симптомы:**
- Время ответа > 10 секунд
- Timeouts

**Диагностика:**

```python
# Проверьте среднее время в админ-панели
# Если > 5000ms - проблема
```

**Решения:**

1. **Оптимизация модели:**
```env
# Используйте более быструю модель
OPENROUTER_MODEL=xiaomi/mimo-v2-flash:free
```

2. **Отключите reasoning для скорости:**
```env
OPENROUTER_REASONING_ENABLED=false
```

3. **Увеличьте timeout:**
```env
OPENROUTER_TIMEOUT=120
```

4. **Включите кеширование:**
```env
REDIS_ENABLED=true
```

### Проблема: Redis недоступен

**Симптомы:**
- Warning "Redis кеш недоступен"
- Кеш не работает

**Решения:**

1. **Проверьте статус Redis:**
```bash
redis-cli ping
# Должно вернуть: PONG
```

2. **Проверьте настройки:**
```env
REDIS_HOST=localhost
REDIS_PORT=6379
```

3. **Проверьте подключение:**
```bash
redis-cli -h localhost -p 6379 ping
```

4. **Временное решение:**
```env
# Отключите Redis
REDIS_ENABLED=false
```

### Проблема: Высокая стоимость использования

**Симптомы:**
- Быстро тратятся средства
- Неожиданно высокие счета

**Диагностика:**

1. Проверьте статистику в админ-панели
2. Посмотрите Activity на OpenRouter
3. Проверьте используемую модель

**Решения:**

1. **Переключитесь на бесплатную модель:**
```env
OPENROUTER_MODEL=xiaomi/mimo-v2-flash:free
```

2. **Включите кеширование:**
```env
REDIS_ENABLED=true
AI_CACHE_TTL=86400  # 24 часа
```

3. **Установите лимиты:**
- В настройках API ключа установите usage limit
- Например: $10/месяц для начала

4. **Оптимизируйте историю:**
```env
# Уменьшите длину истории
AI_MAX_HISTORY_LENGTH=10
```
