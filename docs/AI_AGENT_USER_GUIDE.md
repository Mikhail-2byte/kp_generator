# Руководство пользователя AI агента

## Введение

AI агент помогает работать с данными 1С, рассчитывать логистику, искать материалы и отвечать на вопросы по проекту.

## Основные возможности

### 1. Работа с данными 1С

#### Поиск по номенклатуре
```
Найди в 1с барабан самоцентрирующийся
Найди в Барабанах чертеж 35.1774.000 СБ
```

#### Поиск по заказчику
```
Покажи все записи по заказчику ВАЙЛДБЕРРИЗ
Найди тендеры заказчика X
```

#### Поиск по материалу
```
Найди все позиции с материалом СБ
Покажи записи с материалом 09Г2С
```

#### Статистика
```
Сколько записей в Барабанах?
Статистика по всем категориям
Статистика по тендерам
```

#### Топ-листы
```
Топ заказчиков
Топ материалов
Топ менеджеров по выигранным тендерам
Топ менеджеров по сумме выигранных тендеров
```

#### Специальные запросы
```
Самый большой выигранный тендер
Динамика тендеров по месяцам
Корреляция вес vs цена
Heatmap заказчик менеджер
```

### 2. Расчет логистики

```
Рассчитай логистику из КНР в Екатеринбург за груз весом 5000 кг
Логистика в Москву, вес 2 тонны
Расчет доставки в Санкт-Петербург, 1000 кг
```

### 3. Поиск материалов

```
Найди материал 10
Какой GB у стали 20
Свойства материала 09Г2С
```

### 4. Комбинированные запросы

```
Рассчитай логистику для заказчика X в Москву
Найди в 1с чертеж X и рассчитай логистику в Екатеринбург
```

## Экспорт результатов

Вы можете экспортировать результаты в различных форматах:

- **CSV**: "Экспорт в CSV"
- **Excel**: "Экспорт в Excel"
- **PNG**: "Экспорт графиков в PNG"

## Фильтрация и сортировка

Агент автоматически применяет фильтры и сортировку при необходимости. Вы можете уточнить:
- Фильтр по датам
- Фильтр по цене
- Фильтр по весу
- Сортировка по различным полям

## Графики

Агент автоматически генерирует графики для больших результатов. Вы можете явно запросить график:
- "Покажи график"
- "С графиком"
- "Визуализируй данные"

## Часто задаваемые вопросы (FAQ)

### Как найти конкретный чертеж?
Используйте запрос: "Найди в 1с чертеж [номер чертежа]"

### Как получить статистику по тендерам?
Используйте запрос: "Статистика по тендерам" или "Сколько выигранных тендеров"

### Как экспортировать результаты?
Добавьте к запросу: "экспорт в CSV" или "экспорт в Excel"

### Как получить график?
Добавьте к запросу: "покажи график" или "с графиком"

### Как рассчитать логистику для нескольких записей?
Используйте: "Рассчитай логистику для заказчика X в [город]"

## Подсказки

- Используйте конкретные запросы для лучших результатов
- Можно комбинировать несколько условий
- Добавьте 'покажи график' для визуализации данных
- Укажите категорию для более точного поиска
