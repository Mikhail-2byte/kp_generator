## План улучшений по категориям

### 1. Улучшения функциональности предварительного расчета

#### 1.1 Кэширование и оптимизация
- **Кэширование результатов расчета**
  - Сохранение последнего расчета в `sessionStorage`
  - Проверка изменений данных перед пересчетом
  - Мгновенное отображение кэшированных результатов
  
- **Отмена запросов**
  - Использование `AbortController` для отмены предыдущих запросов
  - Оптимизация использования сетевых ресурсов

#### 1.2 Экспорт и сохранение результатов
- **Экспорт результатов расчета**
  - Кнопка "Экспорт в Excel" для сохранения результатов предварительного расчета
  - Формирование краткого отчета с ценами и маржой
  - Возможность распечатать результаты
  
- **История расчетов в сессии**
  - Сохранение последних 5-10 расчетов в `sessionStorage`
  - Кнопка "История расчетов" для просмотра
  - Возможность вернуться к предыдущему расчету

#### 1.3 Сравнение сценариев
- **Сравнение вариантов расчета**
  - Сохранение нескольких вариантов расчета (разные маржи)
  - Таблица сравнения: маржа 25% vs 30% vs 35%
  - Визуальное сравнение итоговых цен
  - Выбор оптимального варианта

#### 1.4 Визуализация и детализация
- **Детализация расчета по позициям**
  - Раскрывающиеся блоки с деталями для каждой позиции
  - Показ: стоимость закупа, логистика на позицию, маржа, итоговая цена
  - Визуализация структуры цены (круговые диаграммы)
  
- **Визуальные индикаторы изменений**
  - Подсветка измененных значений при пересчете
  - Стрелки вверх/вниз при изменении цен
  - Анимация появления новых значений
