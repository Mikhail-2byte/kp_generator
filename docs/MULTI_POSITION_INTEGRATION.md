# Интеграция множественных позиций в KP Generator

## Обзор изменений

Система была расширена для поддержки множественных позиций в коммерческих предложениях, используя функциональность из `excel_row_inserter.py`.

## Новые файлы

### `app/services/multi_position_processor.py`
- **Назначение**: Обработчик множественных позиций для Excel файлов
- **Основан на**: `excel_row_inserter.py`
- **Функции**:
  - `MultiPositionProcessor` - основной класс для обработки
  - `process_multiple_positions()` - главная функция обработки
  - Автоматическое добавление строк в Excel
  - Копирование стилей и формул
  - Обновление итоговых расчетов

## Измененные файлы

### `app/helpers.py`
- **Добавлено**: `extract_positions_from_form()` - извлечение позиций из формы
- **Обновлено**: `validate_form_data()` - валидация множественных позиций

### `app/document_generator.py`
- **Добавлено**: `generate_single_position_excel()` - для обратной совместимости
- **Обновлено**: `generate_excel_document()` - автоматический выбор метода обработки

### `app/routes/main.py`
- **Обновлено**: `generate()` - обработка множественных позиций
- **Добавлено**: Пропорциональное распределение логистики по позициям
- **Добавлено**: Расчет цен для каждой позиции отдельно

## Как это работает

### 1. Frontend (JavaScript)
- Пользователь добавляет позиции через кнопку "Добавить позицию"
- Каждая позиция получает уникальные имена полей: `product_2`, `quantity_2`, etc.
- Форма автоматически пересчитывает общий вес и логистику

### 2. Backend обработка
```python
# Извлечение позиций из формы
positions = extract_positions_from_form(form_data)

# Расчет цены для каждой позиции
for position in positions:
    # Пропорциональное распределение логистики
    position_logistics = logistics_rub * (position_weight / total_weight)
    
    # Расчет цены позиции
    final_price = calculate_selling_price(...)
```

### 3. Генерация Excel
- **Одна позиция**: Используется старый метод для совместимости
- **Множественные позиции**: Используется `MultiPositionProcessor`
  - Автоматическое добавление строк
  - Копирование стилей и формул
  - Обновление итоговых расчетов

## Структура данных позиций

```python
position = {
    'product': 'Наименование товара',
    'drawing_number': 'Номер чертежа',
    'material': 'Материал',
    'cost_price': '1000',  # Сумма закупа
    'cost_price_per_kg': '100',  # Цена за кг
    'quantity': '5',  # Количество
    'weight': '10',  # Вес за шт (кг)
    'duty_percent': '5'  # Пошлина (%)
}
```

## Маппинг полей в Excel

| Поле формы | Ячейка Excel | Описание |
|------------|--------------|----------|
| product | C | Наименование товара |
| drawing_number | E | Номер чертежа |
| material | D | Материал |
| cost_price | M | Сумма закупа |
| cost_price_per_kg | N | Цена за кг |
| quantity | G | Количество |
| weight | P | Вес за шт |
| duty_percent | X | Пошлина |

## Обратная совместимость

- Старые формы с одной позицией продолжают работать без изменений
- Автоматическое определение количества позиций
- Плавный переход между методами обработки

- Извлечения позиций из формы

## Преимущества

1. **Масштабируемость**: Поддержка неограниченного количества позиций
2. **Автоматизация**: Автоматическое добавление строк и обновление формул
3. **Совместимость**: Работа со старыми формами
4. **Гибкость**: Пропорциональное распределение логистики
5. **Точность**: Отдельный расчет цены для каждой позиции

## Использование

1. Пользователь заполняет форму с множественными позициями
2. Система автоматически определяет количество позиций
3. Для каждой позиции рассчитывается отдельная цена
4. Логистика распределяется пропорционально весу
5. Excel файл генерируется с автоматическим добавлением строк
6. Все формулы и стили корректно обновляются
