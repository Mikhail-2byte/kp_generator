## Обзор

Все функции управления пользователями объединены в один скрипт `scripts/manage_users.py`, который предоставляет удобный интерфейс командной строки с подкомандами.

### Расположение

Скрипт находится в папке `scripts/`:
```
scripts/
  └── manage_users.py
```

### Базовое использование

```bash
python scripts/manage_users.py <команда> [опции]
```

## Просмотр пользователей

### Команда `list`

Показывает список всех зарегистрированных пользователей.

#### Краткий список

```bash
python scripts/manage_users.py list
```

#### Подробный список с хэшами паролей

```bash
python scripts/manage_users.py list --detailed
```

#### Что показывает команда

**Краткий список:**
- Логин (username)
- Роль (admin/user)
- Дата создания аккаунта
- Дата последнего входа

**Подробный список (с флагом `--detailed`):**
- ID пользователя
- Логин (username)
- Роль (admin/user)
- ФИО
- Контактная информация
- Дата создания аккаунта
- Дата последнего входа
- Хэш пароля (первые 60 символов и полный хэш)

#### Пример вывода (краткий список)

```
Найдено 2 пользователей:
- admin@example.com | роль: admin | создан: 2025-12-13 13:00:55 | послед. вход: 2025-12-14 10:30:22
- user@example.com | роль: user | создан: 2025-12-14 09:15:30 | послед. вход: —
```

#### Пример вывода (подробный список)

```
====================================================================================================
Найдено пользователей: 2
====================================================================================================

Пользователь #1
  ID: 1
  Логин: admin@example.com
  Роль: admin
  ФИО: Иванов Иван
  Контактная информация: +7 (999) 123-45-67
  Дата создания: 2025-12-13 13:00:55
  Последний вход: 2025-12-14 10:30:22
  Хэш пароля: scrypt:32768:8:1$Zl4UlLI3f8d5yQ9L$0617eed176e885cc74cd044d05...
  (Полный хэш: scrypt:32768:8:1$Zl4UlLI3f8d5yQ9L$0617eed176e885cc74cd044d05212ea...)
----------------------------------------------------------------------------------------------------
```

#### Примечания

- Пароли хранятся в хэшированном виде и не могут быть восстановлены в исходном виде
- Хэш используется только для технических целей (проверка целостности, отладка)

## Сброс паролей

### Команда `reset-password`

Сбрасывает пароль пользователя. Генерирует новый хэш пароля и обновляет его в базе данных.

#### Использование

```bash
python scripts/manage_users.py reset-password <username> <новый_пароль>
```

#### Параметры

- `<username>` — логин пользователя (email)
- `<новый_пароль>` — новый пароль (минимум 3 символа)

#### Примеры

```bash
# Сбросить пароль для конкретного пользователя
python scripts/manage_users.py reset-password admin@example.com MyNewPassword123
```

#### Пример вывода при сбросе пароля

```
[OK] Пароль успешно сброшен для пользователя: admin@example.com
  Роль: admin
  Новый пароль: MyNewPassword123
```

#### Обработка ошибок

- Если пользователь не найден, скрипт выведет сообщение об ошибке
- Если пароль слишком короткий (менее 3 символов), операция будет отклонена
- Если база данных не найдена, будет выведено соответствующее сообщение

#### Безопасность

- Используется алгоритм `scrypt` для хэширования паролей (через `werkzeug.security`)
- Пароли никогда не хранятся в открытом виде
- Рекомендуется использовать сложные пароли (минимум 8 символов, буквы, цифры, спецсимволы)

## Управление ролями

### Команда `set-role`

Изменяет роль пользователя (назначение ролей `admin` или `user`).

#### Использование

```bash
python scripts/manage_users.py set-role <username> <role>
```

#### Параметры

- `<username>` — логин пользователя
- `<role>` — новая роль (`admin` или `user`)

#### Дополнительные опции

```bash
# Указать путь к базе данных (по умолчанию kp_generator.db в корне проекта)
python scripts/manage_users.py --db /path/to/database.db list
```

#### Примеры

```bash
# Назначить пользователю роль администратора
python scripts/manage_users.py set-role user@example.com admin

# Назначить пользователю обычную роль
python scripts/manage_users.py set-role admin@example.com user
```

#### Пример вывода списка пользователей

```
Найдено 2 пользователей:
- admin@example.com | роль: admin | создан: 2025-12-13 13:00:55 | послед. вход: 2025-12-14 10:30:22
- user@example.com | роль: user | создан: 2025-12-14 09:15:30 | послед. вход: —
```

#### Пример вывода при изменении роли

```
Роль пользователя 'user@example.com' изменена на 'admin'.
```

#### Роли в системе

- **admin** — администратор с полным доступом к системе, включая административную панель
- **user** — обычный пользователь с доступом к основному функционалу генерации КП

## Примеры использования

### Типичные сценарии

#### 1. Просмотр всех пользователей

```bash
# Краткая информация
python scripts/manage_users.py list

# Подробная информация с хэшами паролей
python scripts/manage_users.py list --detailed
```

#### 2. Сброс забытого пароля

```bash
# Сначала посмотреть список пользователей
python scripts/manage_users.py list

# Затем сбросить пароль
python scripts/manage_users.py reset-password user@example.com NewPassword123
```

#### 3. Назначение администратора

```bash
# Просмотреть текущие роли
python scripts/manage_users.py list

# Назначить роль администратора
python scripts/manage_users.py set-role user@example.com admin

# Проверить результат
python scripts/manage_users.py list
```

#### 4. Полный цикл управления пользователем

```bash
# 1. Просмотр всех пользователей (подробно)
python scripts/manage_users.py list --detailed

# 2. Сброс пароля
python scripts/manage_users.py reset-password admin@example.com SecurePassword2025!

# 3. Изменение роли (если нужно)
python scripts/manage_users.py set-role admin@example.com admin

# 4. Проверка результата
python scripts/manage_users.py list
```

Скрипт находится в папке `scripts/`:

- `scripts/manage_users.py` — единый скрипт для всех операций с пользователями

## Безопасность

⚠️ **Важные замечания:**

1. **Пароли хранятся в хэшированном виде** — исходные пароли невозможно восстановить
2. **Хэши паролей** видны только в скрипте `view_users.py` для технических целей
3. **Рекомендуется** использовать сложные пароли (минимум 8 символов)
4. **Скрипты должны выполняться** только администраторами системы
5. **База данных** должна быть защищена от несанкционированного доступа

## Устранение неполадок

### База данных не найдена

Если скрипты не могут найти базу данных:

1. Убедитесь, что файл `kp_generator.db` существует в корне проекта
2. Проверьте, что вы запускаете скрипты из корня проекта
3. Для `manage_roles.py` можно указать путь к БД через параметр `--db`

### Пользователь не найден

Если при сбросе пароля или изменении роли пользователь не найден:

1. Проверьте правильность написания логина (username)
2. Используйте `python scripts/manage_users.py list` для просмотра всех пользователей
3. Убедитесь, что используется правильный регистр символов

### Ошибки кодировки

Если возникают проблемы с отображением русских символов в Windows:

- Убедитесь, что консоль поддерживает UTF-8
- В PowerShell можно установить кодировку: `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`
