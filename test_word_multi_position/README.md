# Тестирование Word Multi Position Processor

Эта папка содержит тесты и скрипты для проверки работы обработки множественных позиций в Word документах.

## Структура файлов

- `analyze_template.py` - Скрипт для анализа структуры Word шаблона
- `test_word_processor.py` - Основной тестовый скрипт для проверки работы процессора
- `test_basic_structure.py` - Проверка окружения и наличия зависимостей
- `test_output_single.docx` - Результат теста с одной позицией (создается после запуска)
- `test_output_multiple.docx` - Результат теста с множественными позициями (создается после запуска)

## Требования

- Python 3.10+
- Установленные зависимости из `requirements.txt` (особенно `python-docx`)
- Файл шаблона `templates_docs/template.docx`

## Запуск тестов

### 1. Проверка окружения

```powershell
python test_basic_structure.py
```

Этот скрипт проверит:
- Установлен ли `python-docx`
- Существует ли файл шаблона

### 2. Анализ структуры шаблона

```powershell
python analyze_template.py
```

Этот скрипт выведет:
- Структуру параграфов с плейсхолдерами
- Структуру всех таблиц
- Информацию о строках и ячейках

### 3. Тестирование процессора

```powershell
python test_word_processor.py
```

Этот скрипт:
- Протестирует работу с одной позицией (обратная совместимость)
- Протестирует работу с множественными позициями
- Создаст выходные файлы для визуальной проверки

## Ожидаемые результаты

После успешного запуска `test_word_processor.py`:

1. ✅ Должен быть создан файл `test_output_single.docx` с одной позицией
2. ✅ Должен быть создан файл `test_output_multiple.docx` с несколькими позициями
3. ✅ В консоли должны быть выведены сообщения об успешном прохождении тестов

## Отладка

Если тесты не проходят:

1. **Проверьте наличие шаблона**: Убедитесь, что файл `templates_docs/template.docx` существует
2. **Проверьте структуру шаблона**: Запустите `analyze_template.py` и убедитесь, что в шаблоне есть таблица с плейсхолдерами позиций
3. **Проверьте плейсхолдеры**: Убедитесь, что в шаблоне используются правильные плейсхолдеры:
   - `{{ product }}`
   - `{{ quantity }}`
   - `{{ cost_price }}`
   - `{{ weight }}`
   - и т.д.

## Структура Word шаблона

Шаблон должен содержать:

1. **Таблицу с позициями** - таблица, в которой есть строка с плейсхолдерами позиций
2. **Строку-шаблон** - строка в таблице, которая содержит плейсхолдеры и будет использоваться для копирования
3. **Общие плейсхолдеры** - в параграфах или других таблицах:
   - `{{ company }}`
   - `{{ date }}`
   - `{{ logistics }}`
   - `{{ delivery_time }}`
   - и т.д.

## Примечания

- Первая строка в таблице позиций обычно является заголовком
- Строка-шаблон обычно находится на второй строке (индекс 1)
- Процессор автоматически находит таблицу и строку-шаблон по плейсхолдерам
