## Что нужно проверить в `templates_docs/template.docx`:

### ✅ 1. Таблица с позициями

В шаблоне должна быть **таблица**, которая содержит строку с плейсхолдерами позиций.

**Структура таблицы:**
- Первая строка (опционально) - заголовок таблицы (например: "№", "Наименование", "Количество", и т.д.)
- Вторая строка (или первая, если нет заголовка) - **строка-шаблон** с плейсхолдерами

**Плейсхолдеры, которые должны быть в строке-шаблоне:**
- `{{ product }}` - наименование товара
- `{{ quantity }}` - количество
- `{{ cost_price }}` - сумма закупа
- `{{ weight }}` - вес за шт

**Опциональные плейсхолдеры:**
- `{{ drawing_number }}` - номер чертежа
- `{{ material }}` - материал
- `{{ duty_percent }}` - пошлина в процентах
- `{{ final_price }}` - цена за единицу (если нужна в таблице)
- `{{ general_prise }}` - общая цена позиции (если нужна в таблице)

### ✅ 2. Общие плейсхолдеры

В параграфах или других таблицах должны быть общие плейсхолдеры:

**Обязательные:**
- `{{ company }}` - название компании
- `{{ date }}` - текущая дата
- `{{ logistics }}` - стоимость логистики
- `{{ delivery_time }}` - срок поставки

**Опциональные:**
- `{{ tender_number }}` - номер тендера
- `{{ delivery_address }}` - адрес доставки
- `{{ final_price }}` - цена за единицу (общая)
- `{{ general_prise }}` - общая цена (общая)
- `{{ final_price_NDS }}` - цена с НДС

## Пример структуры таблицы:

```
┌─────────────┬──────────────────┬───────────┬─────────────┬────────┐
│ №           │ Наименование     │ Количество│ Сумма закупа │ Вес     │
├─────────────┼──────────────────┼───────────┼─────────────┼────────┤
│ 1           │ {{ product }}    │ {{ quantity }} │ {{ cost_price }} │ {{ weight }} │
└─────────────┴──────────────────┴───────────┴─────────────┴────────┘
```

## Как проверить:

1. Откройте `templates_docs/template.docx` в Word
2. Найдите таблицу с позициями
3. Проверьте, есть ли в одной из строк плейсхолдеры `{{ product }}`, `{{ quantity }}`, и т.д.
4. Если есть - шаблон готов! ✅
5. Если нет - нужно добавить таблицу со строкой-шаблоном

## Автоматическая проверка:

Запустите скрипт проверки (в правильном окружении):
```powershell
python test_word_multi_position/check_template.py
```

Скрипт покажет:
- Найдена ли таблица с позициями
- Найдена ли строка-шаблон
- Какие плейсхолдеры найдены

## Если нужно изменить шаблон:

1. Откройте `templates_docs/template.docx` в Microsoft Word
2. Создайте таблицу (если её нет) или используйте существующую
3. Добавьте строку с плейсхолдерами:
   - В ячейках таблицы введите: `{{ product }}`, `{{ quantity }}`, `{{ cost_price }}`, `{{ weight }}`
4. Сохраните файл

**Важно:** Плейсхолдеры должны быть написаны точно так, как указано выше (с двойными фигурными скобками и пробелами).
